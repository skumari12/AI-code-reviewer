# AI Code Reviewer

An AI-powered web-based code review system that analyzes source code and provides automated feedback on code quality, possible issues, security concerns, complexity, and improvement suggestions.

## 📌 Project Overview

**AI Code Reviewer** is a Flask-based web application designed to help students and developers review their source code automatically.

The system allows users to:

- Create an account
- Log in securely
- Submit source code for analysis
- Select the programming language
- Receive code quality feedback
- Get a quality score
- View detected issues and suggestions
- Store code review results in a MySQL database
- Access their reviews through the dashboard

The project combines **Python, Flask, MySQL, HTML, CSS, JavaScript, and static code-analysis techniques** to provide an easy-to-use code review platform.

---

## 🎯 Objectives

The main objectives of this project are:

1. To develop an automated code review system.
2. To identify common programming errors and code-quality issues.
3. To provide useful suggestions for improving source code.
4. To calculate an overall code quality score.
5. To securely store users and review history.
6. To provide a simple web-based interface for students and developers.
7. To demonstrate the practical application of AI/ML concepts in software development.

### 💻 Code Review

Users can:

- Common programming mistakes
- Security-related issues
